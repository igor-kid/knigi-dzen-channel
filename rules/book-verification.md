# Проверка книг: факты, описания, обложки

## Основной источник

**Open Library API** (https://openlibrary.org) — бесплатно, без ключа.

Использовать для:
- проверки оригинального названия, автора, года, ISBN
- получения описаний / аннотаций (на английском)
- получения обложек книг

## Основные эндпоинты

- Поиск: `https://openlibrary.org/search.json?q=...`
- По ISBN: `https://openlibrary.org/isbn/{isbn}.json`
- Work: `https://openlibrary.org/works/{OLID}.json`
- Обложка: `https://covers.openlibrary.org/b/isbn/{isbn}-L.jpg` (S/M/L)

## Проверка русских названий и описаний

Open Library хорошо даёт оригинал и факты, но **русские названия** часто отсутствуют или неверны.

При написании статей **обязательно сверять** русское название, автора и краткое описание по открытым источникам (логин не требуется):

- **LiveLib** (livelib.ru) — карточки книг, отзывы, правильные русские названия
- **Labirint** (labirint.ru) — аннотации, издательства, обложки
- **Book24** (book24.ru) — актуальные издания и описания
- **Читай-город** (chitai-gorod.ru) — русские названия и аннотации

### Порядок проверки

1. Open Library — оригинал, автор, год.
2. Поиск по LiveLib / Labirint / Book24 / Читай-город — правильное **русское название** и краткое описание.
3. Если названия расходятся — брать то, которое стоит на карточке русского издания.

## Правила

- При подготовке статей сначала проверять название и автора через Open Library, затем русское название — по LiveLib / Labirint / Book24 / Читай-город.
- Описания и сюжет брать с этих сайтов или сверять с официальными источниками.
- Не выдумывать названия и факты.

## Дополнительно

- Google Books API (с ключом, квота ~1000/день) — как запасной источник описаний и обложек.
- Всегда указывать источник, если берём прямую цитату или обложку.
