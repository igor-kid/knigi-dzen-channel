# Проверка книг: факты, описания, обложки

## Основной источник

**Open Library API** (https://openlibrary.org) — бесплатно, без ключа.

Использовать для:
- проверки названия, автора, года, ISBN
- получения описаний / аннотаций
- получения обложек книг

## Основные эндпоинты

- Поиск: `https://openlibrary.org/search.json?q=...`
- По ISBN: `https://openlibrary.org/isbn/{isbn}.json`
- Work: `https://openlibrary.org/works/{OLID}.json`
- Обложка: `https://covers.openlibrary.org/b/isbn/{isbn}-L.jpg` (S/M/L)

## Правила

- При подготовке статей про книгам сначала проверять название и автора через Open Library.
- Описания и сюжет брать оттуда или сверять с официальными источниками.
- Обложки для иллюстраций брать из Open Library Covers API.
- Не выдумывать названия и факты. Если в Open Library нет данных — проверять дополнительно (Google Books, официальные сайты).

## Дополнительно

- Google Books API (с ключом, квота ~1000/день) — как запасной источник описаний и обложек.
- Всегда указывать источник, если берём прямую цитату или обложку.
